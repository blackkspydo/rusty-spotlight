26 November 2026 · Version 0.1.0

Install with Homebrew

New

A signed release for Apple silicon and Intel

Follow the Homebrew install instructions and open Rusty Spotlight from Applications. Use Settings to choose whether it opens at login.

23 November 2026

Plugins, and four new things to search

Every feature became a plugin you can switch off. System Settings, Homebrew, clipboard history and file search arrived.

New

System Settings search On by default

Search the places inside System Settings, not only its name. night shift, text replacements, tap to click, microphone or hot corners lists that setting, and Return opens System Settings right there.

About 650 panes and sections, read from the panes installed on your Mac, in your language. Nothing is fetched.

New

Homebrew Off by default

brew ripgrep searches every formula and cask: best name match first, then by installs over the last 30 days. Return installs it and the first row follows the progress. Command-K upgrades, uninstalls, opens the home page or copies the command.

The catalogue is refreshed weekly by a helper process, so the launcher's own memory doesn't grow.

New

Clipboard history Off by default

clip lists recent copies, including images and files, and Return puts one back on the clipboard. Pin the ones to keep. Anything a password manager marks as secret, or copied while Passwords or Keychain Access is in front, is never kept.

Contributed by Aabishkar Aryal in PR #2.

New

File search Off by default

File and folder names from Spotlight's own index, listed under apps once you've typed two letters, or on their own after file. Rusty Spotlight still keeps no index of its own.

Contributed by Aabishkar Aryal in PR #2.

New

Plugins you can switch off

Apps, Ask, Websites, Calculator, Currency, Units, World time and the new plugins can each be turned off in Settings › Plugins, or with enabled = false under [plugins.<name>] in the configuration file. Off means no work at all: with Currency off, no exchange rate is ever fetched.

New

A shortcut per plugin

Give clipboard history, file search or Homebrew a shortcut of its own and the panel opens straight into it: whatever you type searches that plugin. Press it again to close, or another plugin's shortcut to switch.

Improved

Settings › Plugins

Plugins are listed down the left, each with its own page holding its switch, its shortcut and its options: aliases under Apps, keywords under Websites, the default currency under Currency, how long clipboard history is kept.

Fixed

From the code and security reviews

  • Homebrew search is back under 1 ms a keystroke, and its catalogue is let go when the panel closes or the plugin is switched off.
  • A full clipboard history drops the oldest copy, not the one just made.
  • A copy made in an ignored app stays ignored even if you switch apps straight away.
  • A tampered Homebrew index can no longer slip shell text into the command offered for copying, and only web pages open as home pages.
  • A rejected shortcut puts the previous one back.

22 November 2026 · Version 0.0.1

First release

Rusty Spotlight goes public.

New

One field for everything

  • Apps, which learns the results you pick and switches to an app that's already open.
  • Calculator: 15% of 2400. Currency: 100 usd to inr, with live rates kept for offline use.
  • Units: 5 km to mi. World time: 3pm ist to sydney.
  • Websites with your own keywords: gh rust-lang/rust.
  • Ask: ? how do I untar a file asks Claude Code, Codex or Grok, already on your Mac.
  • Command-K for the selected result's other actions.
New

Glass that follows, and a Settings window

The Liquid Glass panel takes each app's colours from its icon, or Aurora, your accent colour, or none. Settings covers the shortcut, open at login, the menu bar icon, glass colour and motion. And an app icon.

Improved

Faster to open, and on the right Space

From the shortcut to the panel on screen in 22 ms typically (was 48 ms). The panel now opens on the Space you're on, including over full-screen apps, where it used to appear off screen.
