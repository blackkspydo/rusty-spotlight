Press two keys. Type a few letters. Done.

Rusty Spotlight replaces Spotlight on macOS 26. It opens apps, does sums, converts money and units, tells the time elsewhere and finds the setting you're after. It's written in Rust, it's on screen in 22 milliseconds, and it's free.

    01 Phrasebook

    What you can say to it

    There's no syntax to learn. Type what you mean and the answer is the first row. Return opens it, or copies it.

    AppsOpens the app, or switches to it if it's already open. It learns which result you pick.
    Calculator360 and 2,832. Return copies the answer.
    Currency$100Live rates, kept on disk so it still answers offline.
    Units3.107 mi, 37.78 °C. Length, weight, temperature and the rest.
    World time3pm ist to sydneyThe time there now, or your meeting in their afternoon. Summer time included.
    System SettingsOpens System Settings at that setting, not at the front door. About 650 places, read from your own Mac.
    Websitesgh rust-lang/rustyt lofiYour own keywords for the sites you search, or a bare address.
    Ask? how do I untar a fileHands the question to Claude Code, Codex or Grok, whichever is already on your Mac, and shows the answer.
    Homebrew off until you askEvery formula and cask, best match first, then most installed. Return installs it.
    Clipboard off until you askclipWhat you copied lately: text, images, files. Anything a password manager marks secret is never kept.
    Files off until you askfile invoiceFile and folder names, from the index macOS already keeps.
    Anything⌘KThe selected row's other actions: Show in Finder, Copy Path, Quit, Copy Link.

    02 Plugins

    Everything has an off switch, and off means off

    Each feature is a plugin. Switch one off and it stops existing: no timer, no network request, no memory held. With Currency off, no exchange rate is ever fetched. Three of them start off, because they watch or index something and that should be your call.

    On when you install

    • Apps
    • Calculator
    • Currency
    • Units
    • World time
    • System Settings
    • Websites
    • Ask

    Off until you ask

    • Clipboard history
    • File search
    • Homebrew

    Clipboard history, file search and Homebrew can each have a shortcut of their own, which opens the panel straight into them.

    03 Weight

    You shouldn't notice it's running

    Measured on an Apple Silicon Mac with about 110 apps installed.

    22msfrom the shortcut to the panel on screen, typically
    <1msfrom a keystroke to new results
    24MBof memory while it waits
    ~0%CPU while hidden: under 10 ms of work a minute

    It keeps no index of its own. Spotlight's figure is its window alone, and leaves out the indexing services macOS runs either way.

    04 Install

    Built on your Mac, from the source

    That takes a minute or two the first time. You need macOS 26 or later.

    # Xcode Command Line Tools and Rust, if you don't have them
xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Build, install to /Applications, and start at login
git clone https://github.com/blackkspydo/rusty-spotlight.git
cd rusty-spotlight
./scripts/install.sh
    1. Press ⌥ Space to open it. A magnifying glass appears in the menu bar.
    2. Allow Input Monitoring when macOS asks, so other apps can't delay or swallow the shortcut. It watches for its own shortcut and nothing else.
    3. To take over ⌘ Space, turn off Spotlight's shortcut in System Settings › Keyboard › Keyboard Shortcuts › Spotlight, then record Command-Space in Rusty Spotlight's Settings.

    Update with git pull && ./scripts/install.sh. Remove with ./scripts/uninstall.sh. The rest is in the README.

    Rusty Spotlight is free and open source. This page is two files and a short video: no fonts downloaded, no trackers, nothing from anyone else's server.
