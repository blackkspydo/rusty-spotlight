Rusty Spotlight

A fast Spotlight replacement for macOS, written in Rust. Same Liquid Glass, same springs, only the things you ask for.

Install View on GitHub

macOS 26 or later · free and open source · built from source on your Mac

Recorded live on a Mac. Glass colour set to Strong.

Everything in one field

Press the shortcut and type. Results paint as you type; Return acts on what you see.

Apps

A few letters and Return. It learns which results you pick, and switches to an app that's already open.

Calculator

12*7, 15% of 2400, 2400 + 18%. Return copies the answer.

Currency

100 usd to inr, $100, 500 aed. Live rates, cached for offline use.

Units

5 km to mi, 70kg in lb, 100 f to c, or just 6 ft.

World time

time in dubai, sydney time, 3pm ist to sydney. Summer time included.

Websites

Your own keywords: gh rust-lang/rust, yt lofi, or a bare address.

Ask

? how do I untar a file asks Claude Code, Codex or Grok, already on your Mac, and shows the answer.

Command-K

The selected result's other actions: Show in Finder, Copy Path, Quit, Copy Link, ask another tool.

Glass that follows

The glass takes each app's colours from its icon and fades as you move. Or Aurora, your accent colour, or plain.

Light on your Mac

Measured on an Apple Silicon Mac with about 110 apps installed.

22 msfrom the shortcut to the panel on screen (typical)
< 1 msfrom a keystroke to new results
24 MBmemory, against 122 MB for Spotlight's own window
~0%CPU while hidden: under 10 ms a minute, and no indexing

Rusty Spotlight searches apps, and optionally file and folder names through Spotlight's own index, so it keeps no index of its own. Spotlight's figure leaves out the indexing services macOS runs anyway.

Install

It's built on your Mac from the source, which takes a minute or two the first time.

# 1. Xcode Command Line Tools and Rust, if you don't have them
xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 2. Build, install to /Applications, and start at login
git clone https://github.com/blackkspydo/rusty-spotlight.git
cd rusty-spotlight
./scripts/install.sh
  1. Press Option-Space to open it. A magnifying glass appears in the menu bar.
  2. Allow Input Monitoring when macOS asks, so other apps can't delay or swallow the shortcut. It watches only for its own shortcut.
  3. To use Command-Space, turn off Spotlight's shortcut in System Settings › Keyboard › Keyboard Shortcuts › Spotlight, then record Command-Space in Rusty Spotlight's Settings.

Update with git pull && ./scripts/install.sh. Remove with ./scripts/uninstall.sh. Everything else is in the README.
