# Sonoma compatibility implementation plan

Implement the approved [design](../specs/2026-11-26-sonoma-compatibility-design.md) inline. Keep the universal binary, existing identities and public 0.1.0 install instructions.

- Exercise the AppKit surface on the main thread. Verify the native view class, retained content, size and both automatic and forced blur selection.
- Share the surface constructor between the launcher and Appearance preview. Look up glass dynamically and guard text-field and editor selectors introduced after Sonoma.
- Target 14.0 in Cargo, the bundle and the cask template. Check workspace tests, both Mach-O slices, dynamic imports, signing, bundle metadata and the local AppKit test.
- Before public release, exercise keyboard focus, searching, opening an app, preview tint and login registration on Sonoma and the modern material on Tahoe or later.
