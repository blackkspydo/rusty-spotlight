Release criteria
  • Set the minimum to macOS 14.0 for both binary architectures, the app bundle, and the Homebrew cask. Check linked symbols and AppKit calls for Sonoma compatibility.
  • Use the same material selection in both windows, preserve the selected app’s tint, and keep the existing bundle identifier, settings, shortcuts, and cask name.
  • Test the signed app on Sonoma: cold launch, global shortcut, app search and launch, Appearance preview, and login-item registration. On Tahoe or later, exercise both glass and forced blur.
